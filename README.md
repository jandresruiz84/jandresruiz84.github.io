# jandresruiz84.github.io

Personal portfolio site for Jesus Andres Ruiz — mechanical engineering student at UTSA, showcasing work on the OpenExo open-source exoskeleton and other projects.

Live at: https://jandresruiz84.github.io/

## Structure

- `index.html` — single-page site (markup, styles, and scripts all in one file)
- `images/` — project photos
- `resume.pdf` — downloadable résumé

## Running locally

Just open `index.html` in a browser — no build step.

## Deployment

Served via GitHub Pages from the `main` branch. Pushing to `main` updates the live site automatically.
